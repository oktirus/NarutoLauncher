Naruto · Коноха — основний нативний лаунчер, розробник Oktirus.

- Оновлення через GitHub Releases: ручна й щоденна фонова перевірка, завантаження з контролем цілісності та підпису, підтвердження встановлення в Android.
- Перший запуск і Home одразу вибирають перший застосунок з ефектом техніки.
- На чистому встановленні увімкнені живий світ, звуки технік і музика Naruto; сцени змінюються кожні 60 секунд, режим спокою — через 15 хвилин.
- Расенґан є початковою технікою, Расенсюрикен іде наступним у каталозі.
- Оновлено «Про Коноху». Chromium/WebView зберігається альтернативною версією.

Збережені користувацькі налаштування при встановленні поверх сумісної версії не скидаються. Для версій без updater цей APK спершу потрібно встановити звичайним способом.
