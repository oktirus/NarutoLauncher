# План розвитку Конохи

## Заплановані техніки навігації

- **Піщаний щит Ґаари.** Пісок піднімається знизу і збирається в золотавий півмісяць за обраною іконкою. При натисканні **OK** щит розсипається по краях картки. [Референс Naruto](https://naruto-official.com/en/news/01_1555)
- **Паперові крила Конан.** За обраною іконкою розкриваються білі крила з паперових пластин. При натисканні **OK** крила розлітаються паперовими метеликами вгору. [Референс Naruto](https://naruto-official.com/en/news/01_2669)

Галерея показуватиме статичні прев’ю обох технік. Коли рух вимкнено, на головному екрані збережеться статичний ефект фокуса.
