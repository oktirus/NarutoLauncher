# 2026-11-11: Фінальні виправлення нативного лаунчера (паритет UI/UX) та підготовка до сліпого аудиту

## 1. Контекст і мета
Після першого контрольного запису синхронізованої сесії (57 дій на Web та Android TV) та сліпого аудиту незалежним аналітиком Antigravity було виявлено ряд невідповідностей геометричного масштабування, блокування D-Pad фокусу у галереї шпалер, відсутність іконки архіву та текстових підписів карток дока.
Мета: реалізувати точкові хірургічні виправлення (Ponytail), перезібрати APK, розгорнути на Lenovo TV, зафіксувати коміт/пуш і провести новий контрольний запис сесії для фінальної верифікації.

## 2. Реалізовані зміни в `NarutoLauncher/native-parity`
1. **`DockView.java`**:
   - Виправлено шлях до ассету іконки архіву з `icons/app-archive.webp` на дійсний `icons/icon-archive.webp`. Іконка успішно відображається (7 452 унікальних кольорів у зоні емблеми).
   - Додано підписи `.app-meta` (`TextView`, 10sp, колір `#a8b8b0`, без темного фону тексту, з вирівнюванням по центру та truncated ellipsize).
   - Для архіву встановлено підпис «Усі застосунки».
2. **`ChakraFocusView.java`**:
   - Базовий радіус фокусу `baseR` приведено у точну відповідність до формули прототипу (`prototype/app.js:303`): замінено множник `0.68f` на `0.45f`. Аура більше не перекриває заголовок секції «Сувої розваг».
3. **`MainActivity.java`**:
   - Скориговано горизонтальний відступ головної оболонки `mainShell` з `dp(61)` на `dp(40)` (відповідає 56 px на щільності TV 227 dpi, збіг із CSS `padding: 28px 4.1% 0`).
   - Розмір годинника `timeView` оптимізовано з `22sp` до `18sp`, відступ годинникового блоку зменшено до `dp(12)`. Годинник більше не накладається на волосся Наруто.
4. **`AndroidManifest.xml`**:
   - Додано обов'язкові категорії запуску лаунчера: `<category android:name="android.intent.category.HOME" />` та `<category android:name="android.intent.category.DEFAULT" />`.
5. **`ScenesPanel.java`**:
   - Додано `setOnKeyListener` з викликом `performClick()` на подіях `KEYCODE_DPAD_CENTER`, `KEYCODE_ENTER`, `KEYCODE_NUMPAD_ENTER`.
   - Зафіксовано 3 колонки (`computedColumnCount = 3`) згідно з CSS прототипу `.scene-grid { grid-template-columns: repeat(3, 1fr) }`.
   - Додано авто-фокус на активну шпалеру при відкритті панелі.
6. **`LibraryPanel.java`**:
   - Зафіксовано 4 колонки сітки (`computedColumnCount = 4`).
   - Прибрано глуху фонову заливку карток (`#102b38`), картки зроблені плаваючими без прямокутних меж (прозорий фон у неактивному стані, золота рамка при фокусі).
   - Додано `setOnKeyListener` для надійного запуску додатків із пульта.
7. **`SettingsPanel.java`**:
   - Випадаючі селектори переведено з повноекранних вертикальних плашок у горизонтальні інлайн-рядки (текст ліворуч, селектор праворуч), що відповідає розмітці `.settings-row` прототипу.
