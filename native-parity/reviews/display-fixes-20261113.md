# Режим спокою, фокус налаштувань і підпис шпалер — 13.11.2026

Виправлено три дефекти нативного лаунчера, оновлено й перевірено Lenovo. Фінальний APK: `releases/KonohaNative-1.0.0-debug.apk`, SHA-256 `5c1cd79dd6bc1c4273144941a4eaf6c0e5f2726f30045facf170cd5c223094d4`.

## Причини та зміни

1. **Накладання під час спокою.** Напівпрозорий AmbientOverlay залишав видимими заголовок, звичайний годинник і док. MainActivity тепер приховує mainShell через INVISIBLE, зберігаючи геометрію та окремий шар шпалер; після виходу повертає VISIBLE і фокус.
2. **Невидимий фокус налаштувань.** Для перемикачів і повзунків додано підсвічування всього рядка; для селекторів — також рамку самого контролу. Активний рядок повністю прокручується в область перегляду. Фіксований фон пунктів випадаючого списку замінено StateListDrawable, який показує selected/focused/pressed/activated стан. Пунктам дозволено переносити довгі назви. Навігаційні посилання та кнопки зберігають існуючі індикатори.
3. **Обрізаний підпис шпалер.** На Lenovo (1366×768, density 227) доступна область відповідає приблизно 963×541 dp. Великий заголовок займав незмінну висоту: дочірній підпис кнопки отримував лише 4 px при висоті тексту 15 px. Тепер вкладена колонка дозволяє стискати заголовок, зберігаючи природну висоту цитати, автора та кнопки; HeroTitleView підлаштовує розмір шрифту до виділеної висоти.

Змінені продуктові файли: MainActivity.java, panels/SettingsPanel.java, views/HeroTitleView.java. Залежності, асети та збережена схема налаштувань не змінені. Попередні незакомічені виправлення збережені.

## Перевірка

- Додано LauncherDisplayRegressionTest на 963×541 dp. Усі чотири тести падають на попередньому коді з очікуваними причинами й проходять після змін.
- Перевірено приховування/відновлення Home у спокої, видимість фокуса всіх дев'яти контролів налаштувань, стан вибраного пункту дропдауна та підписи кнопки для всіх 18 сцен.
- Повна команда в ізольованій ASCII-теці: `gradlew.bat --offline --no-daemon testDebugUnitTest lintDebug assembleDebug --console=plain`.
- **68 тестів, 0 помилок, 0 пропущених; lint 0 Error/Fatal, 29 Warning.** APK зібрано, apksigner verify пройшов.
- Вручну переглянуто програмні Skia-знімки спокою, підпису шпалер і фокуса налаштувань на 963×541. Повна тестова збірка також генерує стандартні TV-знімки панелей.
- `git diff --check` пройшов. Нові зміни точкові; інші існуючі зміни не відкочувалися.

Докази: [verification/display-fixes-20261113](../verification/display-fixes-20261113/), включно з baseline-evidence, журналами Gradle, JUnit XML, lint XML і native-ui PNG. Попередній APK збережено як before.apk для відкату через `adb install -r` без очищення даних.

## Межа приймання

Після окремого дозволу користувача виконано встановлення на `192.168.100.26:5555`, модель LNVNB161216, Android 14, 1366×768, density 227. Перед встановленням збережено попередній APK, приватні дані й налаштування (Windows DPAPI CurrentUser); підпис і контрольні суми перевірено. Дані не очищувалися.

Жива перевірка виявила додаткову неоднозначність: ListView зберігав activated-стан поточного значення, тому водночас виділялися поточне значення та курсор. Фон пунктів дропдауна тепер реагує лише на selected/focused/pressed. Регресійна перевірка падає на попередньому кандидатові та проходить після виправлення. Фінальну збірку повторно перевірено повною командою Gradle: 68 тестів без помилок, lint без Error/Fatal, APK зібрано й установлено.

Підтверджено на самому Lenovo з оглядом скриншотів і XML-ієрархії:

- D-pad Up/Down переносить видимий фокус між рядками, селекторами й повзунками.
- У відкритому списку музики Up переносить єдине виділення з Naruto Main Theme на Strong and Strike; Back закриває список без зміни збереженого треку.
- У спокої присутні лише п'ять текстових вузлів AmbientOverlay; заголовок Home, маленький годинник та док не накладаються. Вихід перевірено через Back і OK.
- Поточний підпис шпалер «Джирая» відображається повністю. Геометрію кнопки для всіх 18 сцен додатково покриває локальний тест.
- Налаштування після всіх тестів семантично збігаються з копією перед першим оновленням. Основний HOME збережено: `com.gathin.tvhome/.MainActivity`.
- На передньому плані фінальний nativeparity; Android Awake, `displayOff=false`. Після фінального встановлення crash-буфер не містить аварій лаунчера.

Введення виконувалося ін'єкцією стандартних Android-клавіш D-pad/OK/Back/Menu через ADB. Фізичні кнопки пульта агент не натискав. Кнопкові маршрути та рендер перевірені на справжньому пристрої; це не перевірка радіоканалу пульта.
