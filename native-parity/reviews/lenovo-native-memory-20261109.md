# Lenovo: встановлення Native Preview та живий замір RAM

09.11.2026, Europe/Kyiv. Виконано за прямим дорученням користувача встановити нативний лаунчер на Lenovo та виміряти ОЗУ.

## Результат

Native Preview встановлено й запущено на підтвердженому Lenovo `LNVNB161216`, `x86_64_tv_go`, Android 14 / API 34, ADB `192.168.100.26:5555`.

- Package: `ua.konoha.tv.nativepreview`, versionCode 1, `1.0.0-native-preview`.
- Встановлений APK перевірено через SHA256 на пристрої: `3BAF18243468B2738F5C52E7FDB53838A611FBA588E32208EB0CF348B5BBDBD1`.
- Вебверсію `ua.konoha.tv` v26 не оновлено й не очищено. Її початковий APK збережено у каталозі доказів.
- Налаштування preview приведено до фактичних налаштувань вебверсії: сцена `team7`, техніка `gamabunta`, motion=true, audio=true, ambience=false, rotation=0, idle=0, ті самі 5 обраних у тому самому порядку. Запис XML preview перевірено зворотним читанням до першого запуску.

## Пам'ять головного екрана

Показник — **сума TOTAL PSS пов'язаних із лаунчером процесів**, KiB / 1024 = MiB. Для вебверсії враховано два процеси, включно з renderer WebView; для native — один. Це не загальна зайнята RAM пристрою й не сума RSS, яка дублює спільні сторінки.

| Сценарій | Середнє PSS, МіБ | Мін.–макс., МіБ | Вибірки |
|---|---:|---:|---:|
| Вебверсія v26, головний екран | 232,30 | 224,69–239,52 | 10 |
| Native Preview, після холодного запуску | 59,82 | 54,96–64,53 | 10 |
| Native Preview, після навігації D-pad та завантаження Гамабунти | **61,48** | **60,74–64,12** | 5 |

Для практичного порівняння використано native **після навігації**, коли ефект виділення вже видно на живому screenshot: **−170,82 МіБ PSS, або −73,53%** від середнього v26. Холодний екран native до першої навігації мав нижче споживання; цей показник не використано для головного висновку про економію.

## Методика та межі

1. Перевірено model/device/API, поточний HOME, видимий застосунок, живлення, standby, версію v26 та відсутність preview. Збережено початковий APK v26 і журнал команд.
2. Поточні налаштування прочитано з WebView через agent-browser, без зміни localStorage. Сесію від'єднано та тимчасовий ADB forward прибрано до вимірювання.
3. Preview встановлено окремим package; звірено SHA256 установленого APK та XML налаштувань.
4. Виконано послідовність **A–B–B–A**: v26 → native → native → v26. Кожний вимірюваний лаунчер запущено через `am start -S -W`, інший тимчасово зупинявся для порівняння. Дані застосунків не очищалися.
5. Перед кожним прогоном — 30 секунд прогріву; далі 5 знімків dumpsys meminfo з інтервалом 2 секунди плюс час самих команд. Фокус перевірявся перед кожним знімком; набір процесів залишався стабільним у межах прогону.
6. Окремо на native натиснуто D-pad Left без запуску стороннього застосунку. На screenshot видно Гамабунту навколо TV Bro. Після 30 секунд прогріву виконано ще 5 вимірювань.

Середні ABBA-прогонів: v26 №1 — 228,29; native №2 — 62,74; native №3 — 56,90; v26 №4 — 236,32 МіБ PSS. Розкид між запусками показує вплив GC, спільних сторінок і стану системи; точну величину не слід переносити на інший TV або інший сценарій.

Виміряно головний екран із вимкненою фоновою музикою. RAM гри, всіх відкритих picker, музики, тривалих циклів і sleep/wake у цьому етапі не вимірювалася. Видимий інтерфейс і навігація підтверджені живими screenshots; це не повне функціональне чи візуальне приймання міграції.

## Фінальний стан і повернення

- Native Preview залишено відкритим; фокус вікна підтверджено.
- Lenovo **Awake**, дисплей увімкнений (`displayOff=false`), зовнішнє живлення підключене.
- HOME залишився `ua.konoha.tv/.MainActivity`: кнопка Home відкриває v26. Системні параметри живлення та standby не змінювалися.
- Тимчасового ADB forward цього тесту немає. Дані вебверсії не очищалися.
- Для повернення до попереднього екрана достатньо натиснути Home. Видалення preview не виконувалося.
