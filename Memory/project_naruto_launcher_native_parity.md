# Naruto TV Launcher: Повна нативна версія (Parity Rewrite)

## Загальні відомості
- **Призначення:** Повне нативне переписування Android TV лаунчера (Коноха / Naruto TV) з Chromium-прототипу (`NarutoLauncher/prototype/index.html`, `NarutoLauncher/android`) на чистий Android SDK (Java 17).
- **Розташування коду:** `NarutoLauncher/native-parity`
- **Пакет додатку:** `ua.konoha.tv.nativepreview` (ідентифікатор `ua.konoha.tv.nativeparity`)
- **Фінальний реліз:** `releases/Konoha-parity-1.0.0-debug.apk` (розмір: 15,573,378 байт, SHA256: `2643078d7b658d908227ed78ffedff5739db98bb0d87e06beb47cbdff81d252a`)

## Архітектура та стек
- **Мова та середовище:** Java 17, Android SDK 34 (minSdk 26, targetSdk 34).
- **Стек:** Android Views + Custom Canvas 2D рендеринг.
- **Жодних сторонніх фреймворків:** 0 WebView, 0 Jetpack Compose, 0 Flutter, 0 Material Components.
- **Збірка:** Використовує кастомний інструмент збірки `tools/build.py parity --stage-root "C:\KonohaBuild"` для уникнення проблем ClassLoader Gradle з кириличними шляхами у Windows.
