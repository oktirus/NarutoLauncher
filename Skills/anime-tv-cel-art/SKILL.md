# Anime TV Cel Art

Створюй нові сцени з мовою малюнка телевізійного аніме. Базовий еталон —
схвалені користувачем Неджи й Чоджі з NarutoLauncher v9. Це спеціалізація
генерації растрових зображень, а не нова модель чи фільтр після генерації.

## Що визначає стиль

- Темні чіткі контури приблизно однакової товщини; небагато внутрішніх ліній.
- Рівні локальні кольори персонажа, один-два тони тіні з чіткими межами.
- Прості відблиски волосся, стримані очі й обличчя відповідно до дизайну серіалу.
- Матовий мальований фон із широких форм: він може мати м'яку гуашеву фактуру,
  тоді як обличчя й одяг залишаються простими cel-площинами.
- Звичайна постановка кадру: зрозуміла дія, читабельний силует, небагато предметів.
- Стримана палітра та освітлення, що відповідають конкретному аніме й сцені.

Слова «аніме», «висока якість» чи «без ШІ» самі цього результату не задають.
Опиши видимі властивості. Не обіцяй невідрізненність від ручного малюнка:
мета — стилістична відповідність, яку потрібно оглянути.

## Референси та задум

1. Визнач серіал, період/версію героя, дію й призначення зображення з запиту.
   Для продовження цього лаунчера використовуй Naruto/Shippuden. Для іншого
   серіалу зміни дизайн і палітру за його кадрами, не перенось костюм Naruto.
2. Візьми кілька справжніх кадрів серіалу: зазвичай 2–4 досить для обличчя,
   костюма, тіней і фону. Віддай перевагу офіційним сторінкам епізодів.
   Переглянь самі зображення; результат пошуку чи дошка без потрібного героя
   не підтверджують його зовнішність. Збережи джерела поруч із матеріалами задачі.
3. Розділи ролі: кадри аніме — дизайн/стиль; затверджений малюнок — орієнтир
   щільності деталей; попередній файл для редагування — окремий edit target.
   Якщо дошка містить інших людей або різний вік, явно вкажи, кого малювати.
   Не перенось випадкові подряпини, бойові ушкодження чи чужі аксесуари.
4. Вибери одну сцену й одну основну дію. Для серії шпалер змінюй ракурс,
   масштаб, локацію й настрій кожного героя, зберігаючи спільну мову малюнка.

Для відтворення схваленого вигляду прочитай
[references/style-and-prompts.md](references/style-and-prompts.md).
Він містить шаблон, спосіб виправлення та посилання на локальні візуальні зразки.
Точні успішні промпти двох сцен — у
[references/approved-prompts.json](references/approved-prompts.json).

## Генерація

- Використовуй доступний built-in генератор зображень. У середовищі Codex
  дотримуйся скілу `imagegen`, якщо він доступний. Для локальних вхідних
  зображень спочатку переглянь їх через `view_image`, потім передай генератору
  підтримуваним способом як референси. Не замінюй запитаний малюнок CSS/SVG.
- Склади промпт із конкретних частин: тип кадру → роль референсів → мова малюнка
  → точний дизайн героя → одна дія → простий фон → композиція → обмеження.
- Новий кадр за дошкою референсів має бути одним цільним зображенням;
  явно виключи колаж, панелі та текст. Для різних героїв роби окремі генерації.
- Обмеження на кшталт «без сяйва» застосовуй до зайвих прикрас. Якщо користувач
  просить чакру, вогонь чи інший ефект, намалюй його у cel-стилі за кадрами аніме.
- Позиція героя праворуч, формат 16:9 і вільні ліві 45% — лише preset шпалер
  цього лаунчера. Для інших завдань композицію визначає запит.
- Для редагування збережи схвалені риси й композицію, змінюй конкретну проблему.
  Якщо прямо просять повну перегенерацію, створи новий кадр, зберігши старий файл.
- Копіюй вибрані оригінали в теку задачі, зберігай промпти, ролі референсів
  і походження файлів. Runtime-кодування роби окремо зі збереженням пропорцій.
  Не називай збільшену картинку нативним 4K.

## Огляд перед прийманням

Порівняй результат з аніме-кадром та еталоном, а не лише з текстом промпту:

- Чи впізнаються герой, його вік, форма очей, волосся, костюм і знаки?
- Чи залишилися тіні пласкими та чіткими, без глянцевої шкіри й об'ємного рендера?
- Чи фон підпорядкований дії, без випадкових орнаментів, зайвого сяйва й мікротекстур?
- Чи правильні руки, кінцівки, предмети й напрямок погляду? Чи немає злитих контурів?
- Чи відсутні випадковий текст, чужі персонажі та перенесені з референсу ушкодження?
- Для UI: чи видно обличчя й силует після реального кадрування і накладання тексту?

Якщо стиль пішов у глянцевий fan art, прибери декоративні деталі з задуму,
посиль прості cel-площини й повтори з потрібним аніме-референсом. Для локальної
помилки зроби точкове редагування. Не намагайся приховати її blur/noise/sharpen.
Генерація стохастична: такий самий промпт не гарантує ідентичний кадр.
